# PULSE AI

### Ask your data. Discover what really matters.

PULSE AI is an AI-powered data intelligence platform that allows users to upload datasets, ask questions in natural language, generate SQL queries, visualize data, detect anomalies, forecast trends, and generate business insights.

## Tech Stack

- Next.js
- React
- TypeScript
- Python
- FastAPI
- PostgreSQL
- Pandas
- NumPy
- Scikit-learn
- LLM
- Plotly
